Interactive Prototype

Start anywhere — every screen links onward the way the app will. The primary loop is Roll → World → Character → Combat. All data shown is illustrative mock content.

The loop — in order

1 · Roll a World →

world list · import · theme/seed/knobs · the forge

2 · Browse the World →

classes · spells · bestiary · tables · raw JSON · rerun same seed

3 · Live in the World →

create · derived stats · pools & spells · conditions · progression · snapshots

4 · Assemble a Fight →

character vs bestiary · theater-of-mind · determinism strip

5 · The Combat Loop →

declare · step · provenanced event log as the stage

Design Language · the visual spec →

palette · typography · components · three moods, live

Switch mood on any screen (top-right) — dark-fantasy, zombie-urban, and a neutral archive mood render one shared system. In the shipped app the mood is driven by the active world's theme (FR-15); the archive mood covers the no-world state and foreign-pack imports.
