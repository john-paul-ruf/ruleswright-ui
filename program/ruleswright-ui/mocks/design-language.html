Motion & accessibility

Transitions ≤ 150ms (buttons, borders, glows). Combat events appear ≤ 120ms fade+rise. Everything honors prefers-reduced-motion. Visible focus rings everywhere; the combat loop is fully keyboard-playable. Never animate a die roll's arithmetic — the roll is text, verbatim (FR-13).
